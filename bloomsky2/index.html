How to change BloomSky Wi-Fi settings (via Bluetooth, SKY2 only)

Put your SKY2 in config mode:
  1. Press the power button for about 3 seconds. All three lights turn on. The SKY2 must end up turned on. If the left light then flashes by itself, the SKY2 is on. If it doesn't, the SKY2 is off, so press the power button again.
  2. Wait about 5 seconds and watch the Wi-Fi icon. If it is already blinking alternate colors, the SKY2 is in config mode, so skip step 3. If it is not, continue to step 3.
  3. Hold the Wi-Fi button for at least 8 seconds.
The SKY2 is in config mode when the Wi-Fi icon blinks alternate colors. If it doesn't, start again from step 1.

SKY2 not in the device list? Check that its Wi-Fi icon is blinking alternate colors and that your computer supports Bluetooth Low Energy. On Windows, you can also try pairing the SKY2 in Bluetooth settings first.
