How to change Bloomsky WIFI parameters (via bluetooth - SKY2 only)

Hard reset your SKY2:
  1. push the power button briefly
  2. hold the wifi button for 8+ seconds
If successful the wifi icon will blink alternate colors.
If unsuccessful please try again.
